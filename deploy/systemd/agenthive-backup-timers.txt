# P509 — AgentHive Tenant Backup Timers

## Systemd Timer Configuration (Alternative to Cron)

Instead of managing /etc/cron.d entries directly, consider using systemd timers for better integration.

### Daily Full-DB Backup (04:00 UTC)
File: /etc/systemd/system/agenthive-backup-full.timer
```
[Unit]
Description=AgentHive Full Database Backup (Daily @ 04:00 UTC)

[Timer]
OnCalendar=daily
OnCalendar=*-*-* 04:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

File: /etc/systemd/system/agenthive-backup-full.service
```
[Unit]
Description=AgentHive Full Database Backup
ConditionPathExists=/var/backups/agenthive

[Service]
Type=oneshot
ExecStart=/opt/agenthive/scripts/ops/agenthive-tenant-backup.sh agenthive prod
StandardOutput=journal
StandardError=journal
```

### Enable Timers
```
sudo systemctl daemon-reload
sudo systemctl enable --now agenthive-backup-full.timer
sudo systemctl enable --now agenthive-retention-prune.timer
sudo systemctl enable --now agenthive-restore-test.timer
```

### Verify
```
sudo systemctl list-timers agenthive-*.timer
```
